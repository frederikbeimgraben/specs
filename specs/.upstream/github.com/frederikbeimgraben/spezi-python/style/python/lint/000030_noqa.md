# Code turns off a ruff rule only when it cannot obey it

Code must turn off a ruff rule with `# noqa` only for a rule that the code cannot obey. The
comment names the code of the rule.

Reason: A turned off rule hides a violation. The code of the rule shows which rule is off.

Test: The ruff rule `PGH004` finds a `# noqa` without a code (spec 000028). A review checks the
cause.
