# The status shows the approval

The `status` of a spec must be one of these values:

| Status | Meaning |
| --- | --- |
| `draft` | The owner did not approve it yet. Its code waits for the approval (spec 000002). |
| `approved` | The owner approved it. Follow it. |
| `replaced` | A different rule replaces it. That rule names it in `replaces`, and `replaced_by` names that rule. |
| `removed` | The rule is not in force. The file stays, so that the number stays taken. |

Reason: The status tells every reader if the owner agrees with the rule.

Test: `spezi check` checks the value.
