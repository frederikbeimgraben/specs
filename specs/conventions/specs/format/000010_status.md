# The status shows the approval

| Status | Meaning |
| --- | --- |
| `draft` | The owner did not approve it yet. Follow it, but ask when it blocks you. |
| `approved` | The owner approved it. Follow it. |
| `replaced` | A different rule replaces it. That rule names it in `replaces`. |
| `removed` | The rule is not in force. The file stays, so that the number stays taken. |

Only the owner must set `approved`. An agent must set it only after the owner approved the spec
in words.

A rule with `status: replaced` must be in `replaces` of a rule with the status `draft` or
`approved`.

Reason: The status tells every reader if the owner agrees with the rule. The new rule names the
old rule, because the copy of a different repository must not change (000048).

Test: `scripts/check_specs.py` checks the value and `replaces`. A review checks who set `approved`.
