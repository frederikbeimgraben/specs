# The index lists every rule

The index `specs/README.md` must list every rule of the project with its ID, title and status,
sorted by ID. A second section must list every rule of the copies of 000048 that applies
(000049), with the long form of its ID (000047). `specs check --write` writes the index
(000065). A person or an agent must not change it by hand. A pull request that adds, moves or
removes a rule must update the index with `specs check --write`.

Reason: A reader finds every rule that applies on one page, and a review sees each new rule in
the diff. The index shows when a reader opens `specs/`.

Test: `specs check` fails when `specs/README.md` is not current.
