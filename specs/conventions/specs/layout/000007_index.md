# The index lists every rule

The index `specs/README.md` must list every rule of the project with its ID, title and status,
sorted by ID. A second section must list every rule of the copies (spec 000048) that applies
(spec 000049), with the long form of its ID (spec 000047). `spezi install` writes the index
(spec 000083). A person or an agent must not change it by hand. A pull request that adds, moves or
removes a rule must update the index with `spezi install`.

Reason: A reader finds every rule that applies on one page, and a review sees each new rule in
the diff. The index shows when a reader opens `specs/`.

Test: `spezi check` fails when `specs/README.md` is not current.
