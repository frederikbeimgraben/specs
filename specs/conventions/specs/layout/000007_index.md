# The index lists every rule

The index `specs/README.md` must list every rule of the project with its ID, title and status,
sorted by ID. `spezi install` writes the index (spec 000083).

Reason: A reader finds every rule that applies on one page. The index shows when a reader opens
`specs/`.

Test: `spezi check` fails when `specs/README.md` is not current.
