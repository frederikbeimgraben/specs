# The index lists every rule

`.specs/index.md` must list every rule of the project with its ID, title and status, sorted by
ID. A second section must list every rule of the copies of 000048 that applies (000049), with
the long form of its ID (000047). `specs/README.md` must be an exact copy of `.specs/index.md`.
`specs check --write` writes both files (000065). A person or an agent must not change them by hand. A
pull request that adds, moves or removes a rule must update both files with
`specs check --write`.

Reason: A reader finds every rule that applies on one page, and a review sees each new rule in
the diff. The copy in `specs/README.md` shows the index when a reader opens `specs/`.

Test: `specs check` fails when `.specs/index.md` is not current or `specs/README.md` is not an
exact copy of it.
