# A rule can be examined

A rule must let a person or a test decide if the code obeys it. It must use numbers, names,
states, status codes and paths. It must not use words such as "fast", "nice" or "intuitive"
without a value that a person can measure.

Reason: A rule that nobody can examine is an opinion.
