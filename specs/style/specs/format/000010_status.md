# The status shows the approval

| Status | Meaning |
| --- | --- |
| `draft` | The owner did not approve it yet. Follow it, but ask when it blocks you. |
| `approved` | The owner approved it. Follow it. |
| `replaced` | A different rule replaces it. `replaced_by` names that rule. |
| `removed` | The rule is not in force. The file stays, so that the number stays taken. |

Only the owner must set `approved`. An agent must set it only after the owner approved the spec
in words.

Reason: The status tells every reader if the owner agrees with the rule.

Test: `scripts/check_specs.py` checks the value. A review checks who set `approved`.
