# Python code needs Python 3.13 or later

Python code must run on Python 3.13 and later. `requires-python` in `pyproject.toml` must be
`>=3.13`. The target version of ruff and basedpyright must be 3.13.

Reason: The code uses the `type` statement, `match` and the current typing features.
