# The CI job runs spezi check

The CI job that `spezi init` writes (spec 000066) must run `spezi check` at the commit of the kit.
On GitHub and Codeberg, it must run for each pull request and for each push to the branch of
`base_ref`, for example `develop` for `origin/develop`. For Codeberg, the job must run on the
hosted Forgejo Actions runner `codeberg-small`.

Reason: Each change of the project gets the check before the merge.

Test: `tests/test_kit.py`.
