# With ci off, a command ignores the GitLab file

When the switch `ci` is off (spec 000084), a command must not stop because `.gitlab-ci.yml` has
an `include` that is not a list.

Reason: Without the CI part, the kit does not change `.gitlab-ci.yml`.

Test: `tests/test_features.py`.
