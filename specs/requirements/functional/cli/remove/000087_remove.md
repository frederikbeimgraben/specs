# spezi remove removes the copy of a different repository

`spezi remove <repo>` must remove the table `[upstream."<repo>"]` from `spezi.toml`, the folder
`specs/.upstream/<repo>/` with each empty folder above it, and the entry of `<repo>` in
`spezi.lock` (spec 000082).

Reason: A project stops to use the rules of a repository with one command.

Test: `tests/test_configure.py`.
