# specs remove removes the copy of a different repository

`specs remove <repo>` must remove the table `[upstream."<repo>"]` from `specs.toml`, the
folder `specs/.upstream/<repo>/` with each empty folder above it, and the entry of `<repo>` in
`specs.lock` (000082). The other lines of `specs.toml` must stay. Then the command must do the
steps of `specs install` (000083). The command must stop with an error and change no file when
`<repo>` is the kit or is not in `specs.toml`.

Reason: A project stops to use the rules of a repository with one command, and the kit stays,
because the project needs its templates and its migrations.

Test: `tests/test_configure.py`.
