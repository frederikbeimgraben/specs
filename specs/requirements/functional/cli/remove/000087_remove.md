# spezi remove removes the copy of a different repository

`spezi remove <repo>` must remove the table `[upstream."<repo>"]` from `spezi.toml`, the
folder `specs/.upstream/<repo>/` with each empty folder above it, and the entry of `<repo>` in
`spezi.lock` (spec 000082). The other lines of `spezi.toml` must stay. Then the command must do the
steps of `spezi install` (spec 000083). The command must stop with an error and change no file when
`<repo>` is the kit or is not in `spezi.toml`.

Reason: A project stops to use the rules of a repository with one command. The kit stays,
because the project needs its templates and its migrations.

Test: `tests/test_configure.py`.
